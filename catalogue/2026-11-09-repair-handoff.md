## 5. Environment constraints (must-know for the returning model)

- Shell is Nushell 0.115 on win32. No `&&`, no `||`, no `export VAR=`,
  no `2>&1`, no `$(...)`. Sequence with `;`. Merge stderr with `o+e>|`.
  Read exit codes directly.
- `nu split words` splits on punctuation: `README.md` becomes `md`. Use
  `str replace -r '.*\s' ''` to extract paths from `git ls-files --eol`
  output.
- `git add --renormalize` only re-adds tracked files; stage new files
  (.gitattributes) explicitly.
- Multi-command bash calls: only the LAST command's output renders. One
  output per call, or verify separately.
- Bash tool denies: `cat`, `head`, `tail`, `grep`, `rg`, `sed`, `awk`,
  `find`, `python`, `python.exe`, `python3` as bare commands. Use nu
  builtins (`open`, `lines`, `first`, `where`, `str contains`), `^git`,
  `uv`, `node`, `bun`, `npm` are fine. `uv run python ...` is allowed
  (the deny pattern is bare `python *`).
- todowrite: pass todos as a real JSON array; compact single-line content
  with `\n` escapes works; huge multi-line payloads previously failed
  schema parse (payload shape, not a size limit).
- Encoding rule: UTF-8, LF, no BOM, no CR — verify after every write.
