/v1/messages for Claude Code and cannot sit in front of the OpenCode
pipeline (survey D-joint). Its two functions are therefore ported, not
proxied, and the proxy itself gets the same caps for Claude Code use:

- Target Context = verbatim tail preserved after compression.
- Compact Target (Trigger) = total at which compression starts.

Amended by operator 2026-10-26 (RTR-RE:Rolling): keep everything verbatim
until 200-220k, cut only ~50% to 80-100k; evicted substance is kept
verbatim for the RTR dual-ONNX DTD index (evict_payload), so compression
loses position, never substance. Collision rule: exactly one mutator per
transport — Rolling proxy (Claude Code) or ACP compress (OpenCode); the
RTR planner is advisory and never mutates messages. ACP duplicated
compression features stay unused where Rolling already owns the act; ACP
is kept for window selection (acp.jsonc), tiers, decompress and search.
